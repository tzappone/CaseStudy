# Subway Case Study - Implementation of Facial Recognition Technology
## Description
The below case study provides an analysis of Subway's Grab & Go smart fridges and whether Subway should implement facial recognition technology into the unattended vending machines. Key factors are considered to provide an alternative, including Subway's current market position, impacts on key stakeholders, and the competitive advantages provided.
